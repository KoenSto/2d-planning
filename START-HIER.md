# Start hier

## Snel lokaal bekijken

Open een terminal in deze map en voer uit:

```bash
python3 -m http.server 4173
```

Ga vervolgens in de browser naar `http://localhost:4173`.

## Op GitHub plaatsen

1. Maak een lege repository met standaardbranch `main`.
2. Upload de volledige inhoud van deze map, inclusief `.github`.
3. Ga naar **Settings > Pages**.
4. Kies bij **Source** voor **GitHub Actions**.
5. Open **Actions** en controleer de workflow **Test en publiceer op GitHub Pages**.

Na een geslaagde workflow staat de URL bij de deployment vermeld.

## Eerste gebruik

1. Zoek een adres.
2. Zoom in en laad kavels.
3. Selecteer het plangebied.
4. Teken bebouwing, groen, parkeren en openbare ruimte.
5. Pas bouwlagen en rekenaannames aan.
6. Exporteer belangrijke scenario's als JSON.

Meer uitleg staat in `README.md`.
